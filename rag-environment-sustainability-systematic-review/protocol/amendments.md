# Registro de Alterações do Protocolo

Este arquivo registra toda alteração metodológica realizada após a criação do protocolo inicial. Alterações anteriores ao congelamento da versão `v1.0` também devem ser registradas quando modificarem decisões previamente documentadas.

| Data | Versão | Alteração | Justificativa | Impacto |
|---|---|---|---|---|
|  |  |  |  |  |

## Regras de preenchimento

- **Data:** usar o formato `AAAA-MM-DD`.
- **Versão:** informar a versão resultante da alteração, por exemplo `v0.2` ou `v1.1`.
- **Alteração:** descrever objetivamente o que mudou.
- **Justificativa:** registrar a evidência ou problema que motivou a mudança.
- **Impacto:** indicar se a alteração afeta busca, elegibilidade, triagem, extração, qualidade, síntese ou outro componente.

Nenhuma alteração deve ser realizada silenciosamente.
